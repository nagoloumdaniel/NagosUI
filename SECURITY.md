# Politique de sécurité

NagosUI est en développement actif (early-stage) ; aucune version n'est publiée sur npm.
Seule la branche `main` (et le site https://nagosui.vercel.app) est considérée comme supportée.

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique**. Utilisez le signalement privé de GitHub :
onglet **Security** > **Report a vulnerability**
(https://github.com/nagoloumdaniel/NagosUI/security/advisories/new).

Indiquez : description, étapes de reproduction, impact estimé. Pas de SLA formel (projet personnel) ;
un accusé de réception est visé sous quelques jours.
